잉팟 개인정보처리방침

시행일: 2026년 10월 18일 (버전 2026-10-18)

잉팟(이하 "앱")은 영어 팟캐스트를 대본·번역·표현과 함께 들을 수 있게 돕는 학습 앱입니다. 앱은 서비스 제공에 꼭 필요한 정보만 처리하며, 개인정보를 판매하지 않습니다. 소식 메일은 이용자가 따로 동의한 경우에만 보냅니다.

1. 처리하는 정보

항목목적
[필수] 이메일 주소로그인, 계정 식별, 서비스 관련 안내(유료 이용 시 결제·환불 안내 포함)
[필수] 닉네임앱 안에서 이용자 표시
[필수] 약관·개인정보 동의 기록(동의한 버전과 시각), 만 14세 이상 확인동의 사실의 증빙
Google·카카오로 로그인하는 경우: 해당 계정의 이메일, 이름, 프로필 사진 주소로그인과 계정 식별
알림용 기기 토큰(푸시 토큰)과 알림 설정학습자료 준비·새 에피소드 알림 발송(앱의 나 화면에서 끌 수 있음)
[선택] 소식 메일 수신 동의 여부와 시각새 기능·이벤트 안내 메일 발송(동의한 경우에만, 언제든 철회 가능)
구독한 쇼, 들은 에피소드와 듣기 위치, 학습자료를 만든 에피소드홈 화면 구성, 이어 듣기, 주간 무료 이용량 계산
저장한 단어·표현과 복습 기록단어장과 복습 기능

앱은 위치 정보, 연락처, 마이크, 사진 등 기기 정보에 접근하지 않으며, 별도의 분석·광고 도구를 사용하지 않습니다.

2. 보관 기간과 삭제

정보는 계정이 유지되는 동안 보관됩니다. 앱의 나 → 계정 삭제에서 언제든 계정을 삭제할 수 있으며, 삭제하면 위 정보가 즉시 지워지고 되돌릴 수 없습니다. 앱을 쓸 수 없는 경우의 삭제 방법은 계정 삭제 안내를 참고하세요.

3. 처리 위탁

  • Supabase: 계정 인증과 데이터 저장(데이터베이스 호스팅)
  • Google, 카카오: 이용자가 선택한 경우의 소셜 로그인
  • Expo, Google(Firebase Cloud Messaging): 푸시 알림 전달(기기 토큰과 알림 문구만 전달)
  • GitHub: 에피소드 대본·번역 자료를 만드는 서버 작업 실행. 사용자 개인정보는 전달되지 않습니다.
  • Anthropic: 팟캐스트 대본의 번역과 단어·표현 정리. 팟캐스트 공개 대본만 전달되며 사용자 정보는 전달되지 않습니다.

4. 제3자 제공

법령에 따른 요청이 있는 경우를 제외하고, 이용자의 개인정보를 제3자에게 제공하지 않습니다.

5. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않습니다. 가입할 때 만 14세 이상임을 확인받으며, 만 14세 미만의 개인정보를 알게 되면 지체 없이 삭제합니다.
